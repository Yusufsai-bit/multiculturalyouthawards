# Whole-site quality improvement

## Goal
Polish every public page using the supplied inspection checklist while preserving the established Multicultural Youth Awards identity, content purpose and UK English.

## What will change
- Review and refine wording that is repetitive, awkward, generic or inconsistent, without changing factual meaning.
- Correct current factual and status inconsistencies, including event location wording, nominations-closed messaging, age wording, partner-year labels and the copyright year.
- Standardise headings, labels, calls to action and form language across Home, About, Awards, Nominations, Partners, Winners, Contact and legal pages.
- Improve spacing, alignment, type hierarchy, readability, button consistency and mobile presentation using the existing white, navy and gold system.
- Improve accessibility: labelled form fields, keyboard focus, semantic controls, useful link wording, reduced-motion behaviour and appropriate image treatment.
- Remove dead-end actions caused by closed nominations and direct visitors towards relevant current actions such as tickets, winners or updates.
- Check shared navigation and footer presentation so every page feels part of the same site.

## What will stay unchanged
- MYA logo, brand colours, Playfair Display and Inter typography, premium awards aesthetic and top gold announcement banner.
- Official category names, winner/finalist records, partner organisations, event details and the existing private seating/admin areas.
- The “How to Nominate” section will remain available, with wording clarified only where needed.

## Technical approach
- Reuse current design tokens and shared controls; no new visual theme or hardcoded colour system.
- Keep content and layout changes within public-page and shared presentation files unless a displayed database record contains a confirmed inconsistency.
- Validate all nine public pages at desktop and mobile sizes, checking overflow, broken interactions, images, links, forms and browser errors.
- Perform a final copy and visual quality pass against the uploaded checklist before completion.

## Completion checks
- Every public page renders without horizontal overflow or new errors.
- Current 2026 status is consistent: nominations closed, tickets live and eligibility aged 16–25.
- Typography, button treatment, casing and section spacing are consistent across pages.
- Final report summarises improvements and gives concise quality scores for language, typography, visual design, consistency, UX and professionalism.
